# User Story

## Task Management System

### User Story

> **As a** busy professional,  
> **I need** a simple way to manage my daily tasks with due dates,  
> **So that** I can stay organized and track my progress.

### What I can do

**Account:**
- Register with name, email, and password
- Log in and log out
- My tasks are private (only I can see them)

**Tasks:**
- Create tasks with title, description, and due date
- View all my tasks
- Edit task details and status
- Delete tasks
- Filter tasks by status (Pending, In Progress, Completed)
- See which tasks are overdue

### Validation Rules

- Title is required (max 200 characters)
- Due date cannot be in the past
- Password must be at least 8 characters
- Email must be unique
